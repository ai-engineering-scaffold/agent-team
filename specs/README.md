# Specs

One file per feature, `NNN-short-name.md`, written by the spec writer with the `write-spec` skill (`plugin/skills/write-spec/SKILL.md` has the template). Spec PRs are opened with `status: approved` already set, and Graham approves a spec by merging its PR (gate 1). Changes are requested in PR comments, and a spec he doesn't want stays open or is closed. Once merged, the agent pipeline plans it.
